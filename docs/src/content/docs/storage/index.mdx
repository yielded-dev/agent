Storage answers what survives a restart. A host answers who can execute now.
Keeping conversation history and recovering unfinished work are separate choices;
a database alone does not start workers or drive recovery.

## Connect storage to execution

| Need                                       | Assembly                                                                                      |
| ------------------------------------------ | --------------------------------------------------------------------------------------------- |
| Conversation within one application Scope  | [InMemory.layer](/storage/memory/)                                                            |
| Successful Runs retained across restarts   | `PersistentHistory.layer` with [SQLite](/storage/sqlite/) or [PostgreSQL](/storage/postgres/) |
| Accepted work recovered after interruption | [Node](/platforms/node/) or [Cloudflare](/platforms/cloudflare/) durable host                 |

For example, a chat that only needs yesterday's completed conversation can use
persistent history. An accepted research job that must continue after process loss
needs durable execution. Both reuse a Thread ID for follow-ups.

Durable storage retains canonical history, current execution checkpoints, admissions,
and unresolved operations. Settlement deletes the finished Run's checkpoint.
Projections are disposable. Every backend requires one live owner per Thread;
PostgreSQL does not add distributed ownership.

## Back up or change record formats

Export an idle Thread with `streamExport`, keep the source quiescent until all pages
are saved, then import the completed archive into an empty destination Thread.
Pending work, approvals, unknown outcomes, or deliveries can prevent export.
See [operations](/guide/operations/) for the procedure.

Adapters reject unsupported or ambiguous storage layouts and record formats without changing
the store.

## Build another adapter

`@yielded/agent-storage-sql` provides shared SQL implementations. Durable adapters
must co-own the Thread log, Submission ledger, and atomic settlement publisher.
Start with the [package map](/reference/packages/#effect-agent-storage-sql) and
[adapter verification](/guide/testing/).
