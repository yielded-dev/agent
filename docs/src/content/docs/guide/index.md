Start with the [runtime model](/concepts/runtime-model/) and [durability guarantees](/concepts/durability/)
if you are evaluating the library. The [getting-started example](/guide/getting-started/)
runs an agent without setting up a durable host.

| Next decision                           | Read                                             |
| --------------------------------------- | ------------------------------------------------ |
| What does the agent know and produce?   | [Agent definitions](/guide/agents/)              |
| What can it do?                         | [Tools](/guide/tools/)                           |
| How do users follow and steer it?       | [Run and stream](/guide/run-agents/)             |
| What survives the next request?         | [Threads](/guide/threads/)                       |
| How does it handle a long conversation? | [Context management](/guide/context-management/) |
| Where does accepted work run?           | [Platforms](/platforms/)                         |
| What must the host operate?             | [Operations](/guide/operations/)                 |

Add [subagents](/guide/subagents/) or [messaging](/guide/messaging/)
when work needs separate lifetimes. [Testing](/guide/testing/) explains deterministic model
fixtures and storage adapter certification.
